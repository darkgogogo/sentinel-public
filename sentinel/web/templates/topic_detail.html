关键词怎么生效？

每 6h（02:30 / 08:30 / 14:30 / 20:30）跑 alert service 时，对该主题的新增消息做两层过滤：

  1. 第一层 keyword 过滤（这里设的）：
    只让 substring 命中任一关键词的消息进入下一层。 VLESS 协议被封 命中关键词 VLESS，会进入第二层； 今天天气不错 没命中任何关键词，直接丢弃，不消耗 LLM。
  2. 第二层 LLM 判定（triage）：
    经过滤的消息送 Claude Haiku，结合 monitor_direction 判断是否值得告警。

无关键词时：所有新消息都进 LLM（成本高但漏报少）。
关键词太严：用词不同的相关消息会漏（false negative）。
某信源勾"直通"（在"关联信源"列）：该源所有消息跳过第一层，直接进 LLM。

最佳实践：每个 topic 配 5-15 个高频核心词；每月 review 一次。
