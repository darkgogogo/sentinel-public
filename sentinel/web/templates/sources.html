💬 Telegram
  • 格式 @channel_name（公开频道）或纯数字 chat_id（群组）
  • 前置条件：secrets/.env 配 TELEGRAM_API_ID + TELEGRAM_API_HASH，首次跑 collect 会用 telethon 登录
  • 示例：@gfwknocker · @durov
  • 限制：需公开频道或本帐号已加入的群组；私聊不支持
📡 RSS / Atom Feed
  • 格式：完整 URL，如 https://example.com/feed.xml
  • 本机 RSSHub 已长驻 127.0.0.1:1200，社交平台用本机 URL 走 RSSHub：
V2EX 最新 http://127.0.0.1:1200/v2ex/topics/latest
V2EX 热门 http://127.0.0.1:1200/v2ex/topics/hot
B 站动态 http://127.0.0.1:1200/bilibili/user/dynamic/{uid}
即刻用户 http://127.0.0.1:1200/jike/user/{user_id}
GitHub release http://127.0.0.1:1200/github/repos/{owner}/{repo}
Solidot https://www.solidot.org/index.rss

⚠️ 知乎 / 小红书 / 微博 反爬太强，本机 RSSHub 也常 503 → 改用 inbox 兜底。 完整 routes：docs.rsshub.app

🐦 Twitter / X
  • 格式：用户名（不带 @），如 elonmusk
  • 前置条件：secrets/.env 配 SOCIALDATA_API_KEY（付费 API · ~$10/月）
  • 示例：vpnnews_cn · jack
  • 限制：仅支持单一用户 timeline；搜索 / hashtag 请用 RSSHub /twitter/keyword/...
🤖 Reddit
  • 格式：subreddit 名（不带 r/），如 selfhosted
  • 实现：直接抓 reddit.com 的 .rss 端点，无需 API key
  • 示例：selfhosted · VPN · ProtonVPN · privacy
  • 限制：reddit 偶尔限流；多个 subreddit 各自建一个 source
📥 Inbox（web-access 兜底）
  • 格式：<topic-slug>，对应 KB 目录 inbox/<slug>/*.md
  • 用法：用 web-access skill 抓任意页面 → 落 markdown 到该目录 → 下次 collect 自动 ingest（改名 .md.ingested 防重复）
  • 示例 slug：my-topic · another-topic（直接用 topic 的 slug，斜杠空格自动转 -）
  • 适用：知乎话题 / 小红书 / 微博搜索 等强反爬平台 + 长尾源 + 一次性调研落地
  • 注意：source 还需 link 到对应 topic（在 topic 详情页操作）
